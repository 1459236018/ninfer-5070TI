# SHA256SUMS.txt -- manifest for THIS repository.
#
# Every path is relative to the repository ROOT, with forward slashes.
# Check from the repo root:   powershell -File verify-kit-manifest.ps1 -Kit .
#
# Scope: the 12 runtime DLLs beside the engine, plus the files under docs/.
#
# LINE ENDINGS -- read this before reporting a mismatch
#   Every digest below is of the file EXACTLY AS IT LIES ON DISK (byte-exact). That is what an
#   unzipped release archive contains, and it must always pass.
#   A git checkout is a different story: .gitattributes marks text files `text=auto`, so git
#   stores them with LF while a Windows working tree -- and the zip built from it -- carries
#   CRLF. One text file therefore legitimately has two digests.
#     - docs/SHA256SUMS.lf.txt   pairs each TEXT file with its digest AFTER CRLF->LF, so a
#                                clone that came down as LF can be verified too.
#     - verify-kit-manifest.ps1  checks this file first, byte-exact. Only for entries that fail
#                                there does it consult the companion, and a hit is reported as
#                                CRLF-ONLY -- never as a pass over modified bytes.
#   Binaries are deliberately absent from the companion: a .dll packed with the byte pair
#   0x0D 0x0A uses it as machine code, not as a line break. Normalising one would hash a file
#   that does not exist and could mask a single-byte modification. DLLs are byte-exact, always.
#
# NOT covered, by design:
#   - engine/ninfer-serve-120a.exe  -- the engine binary is a Release asset, not in this repo.
#     Per-file hashes for that asset are in the release attachment:
#       ninfer-engine-pack-<date>.zip.sha256          (whole archive)
#       ninfer-engine-pack-<date>.zip.manifest.txt    (per file)
#   - start-*.bat, verify-*.ps1, engine/pick-engine.bat, tools/*, AGENTS.md, README.md,
#     LICENSE, NOTICE
#     -- these change as the repo evolves; pin them by commit instead.
#   - SHA256SUMS.txt and SHA256SUMS.lf.txt themselves -- a manifest cannot contain its own
#     digest, and a companion built from it would be circular.
#
