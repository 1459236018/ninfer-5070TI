# 规划与实验报告（本地归档，不入库）

这个目录是**开发过程中的规划与实验记录**，不是分发包的一部分。

## 为什么不入库

- 里面含有**本机绝对路径**（盘符、用户名、构建机路径），公开仓库不保留这些
- 其中多数是对既有结论的过程性记录，最终结论已经收敛进 [`AGENTS.md`](../AGENTS.md)
  和 [`docs/MODEL.txt`](../docs/MODEL.txt)
- 图片类报告（`*.html`）体积较大，对 clone 者是噪音

## 如果确实要发布

把文件里的路径替换成相对路径或占位符（`D:\...` → `<包目录>`，
`E:\<build-root>\...` → `<构建根>`），再逐个 `git add -f`。
`AGENTS-NInfer-引擎调优交接.md` 与本仓库 `AGENTS.md` 内容高度重叠，建议只保留后者。
